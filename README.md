# Colorado Wildfire + Flood Map (Draft)

Rebuild by Design's interactive map of flood and wildfire risk to properties and public assets in Colorado. Draft: flood only for now; wildfire is coming.

Live: https://rebuildbydesign.github.io/co-wildfire-flood-map/

Static site, no build step. Mapbox GL JS v3. Data in `data/`, vector tiles in `tiles/`.
